# Changelog

All notable changes to MojoMind are documented in this file.
The format loosely follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## [Unreleased]

## [1.5.0] - 2026-07-26

### Added

- SHOUT-IT-NOW colour palette applied to every flower mark and generated PWA icon.
- On-device colour analysis for uploaded pictures, with a short Mojo Guide colour note and palette swatches (no diagnostic claims).
- Slow, non-blocking segmented SHOUT colour ribbon around the app edge.

### Project

- Added `package.json`, `CHANGELOG.md`, `LICENSE.md`, `.editorconfig`, `.gitattributes`, and `robots.txt`.
- Reorganized the outer workspace's reference material into `design-source/` (recordings, deck, brand originals, analysis frames) and fixed the empty `workspace.code-workspace` folder list.

## [1.4.0] - 2026-07-26

### Added

- Deeper indexed Mojo Guide: 14 knowledge topics grounded in the current activity (materials, steps, uploads, reflections, progress, privacy, offline use, support pathways, breathing, incentive, mood garden, Daily Spark).
- Conversational follow-up memory (e.g. "yes please" continues the last topic).
- Sticky survey progress bar on mobile so progress stays visible while scrolling.
- Mood garden now starts with one welcome flower before any check-in.
- Four randomized, non-repeating tap/click particle "aura" styles.

## [1.3.0] - 2026-07-26

### Added

- SHOUT-IT-NOW branded mobile-number sign-in screen (logo lockup + ambient colour-cloud watermark).

### Changed

- Sign-in heading and button copy clarified to "Mobile Number Sign In" / "Sign in with number".

## [1.2.1] - 2026-07-26

### Added

- Interactive, animated mood check-in faces (pointer-following eyes, hover/tap reactions, reduced-motion support).

## [1.2.0] - 2026-07-26

### Added

- Click Aura "Jump Forth" particle-burst effect on every tap.
- Intent-aware facilitator AI with crisis-safe routing to Help Now and helplines.
- ION orbit brand mark replacing the placeholder lightning icon.

### Fixed

- Custom domain (`hellion.solutions` → `www.hellion.solutions`) made canonical with HTTPS enforced.

## [1.1.0] - 2026-07-26

### Added

- Daily Spark hold-to-charge inspiration ritual with a personal constellation.
- Three-state demo reset (choose a study group, then land on Home).
- IONITY Global (Pty) Ltd footer branding with `www.ionity.co.za` links.
- Initial `hellion.solutions` custom domain wiring.

## [1.0.0] - 2026-07-26

### Added

- Initial MojoMind Creative Resilience PWA: full onboarding flow, demographic
  questionnaire, Pre/Post surveys (PHQ-9, GAD-7, MARS-5, Stigma-5, BRS,
  CAGE-AID, usability), 8 weekly art activities, group/individual chat,
  Support Services, Help Now with guided breathing, mood garden, offline
  service worker, and installable manifest.
- Private GitHub repository and GitHub Pages hosting under
  Ionity-Global-Pty-Ltd.
